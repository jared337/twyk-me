# Model photos

Drop real photos of printed models here (jpg/png/webp), then reference them
from the model's entry in `../js/data.js`:

```js
{
  id: "knight",
  ...
  images: ["img/knight-1.jpg", "img/knight-2.jpg"],
}
```

- The first image becomes the card thumbnail on the homepage and explore pages
  (replacing the auto-generated 3D render).
- All images appear in the model page gallery, between the live 3D view and the
  auto-generated angle shots.

Only use photos you own the rights to (your own prints or creator-submitted
uploads) - not images taken from other platforms.
