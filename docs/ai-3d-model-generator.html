Design 3D prints with AI: ask, send a photo, or build with code

AI twyk builds printable 3D models for you, using the same tools you do, so every step can be undone and every part edited. This tutorial shows real requests: a headphone hook from one sentence, changed by naming its parts, a desk cable clip built from a photo, and a detailed red telephone box made with Build with code, which looks up the real thing and checks every build. The waiting is sped up in the video.

Step by step

  1. A request that works

    Describe what you want in a sentence or two, like the headphone hook in the video. The more concrete the request, the better the result, and AI twyk checks its own work as it builds.

  2. Changing parts by name

    Every part has a name, so you can ask for a change to just that part instead of starting again.

  3. Suggested next steps

    After each build AI twyk suggests what to do next, so you can keep going with a click.

  4. Building from a photo

    Send a photo and ask for a model of what is in it, like the desk cable clip. You choose which AI builds, and the video shows which is best with pictures.

  5. History

    Chat History keeps your earlier requests, so you can come back to a design later.

  6. Build with code

    For detailed models, Build with code writes the whole build as one program. It looks up the real thing, like the red telephone box, and checks every build.

  7. Tips for the best results

    A closing set of tips for getting the best results from AI twyk.

Frequently asked questions

Can I still edit what the AI builds?

Yes. AI twyk uses the same tools you do, so every part is editable and every step can be undone.

Can AI twyk build a model from a photo?

Yes. The video builds a desk cable clip from a photo, and shows which AI is best when you send pictures.

What is Build with code?

A mode for detailed models. AI twyk writes the whole build as one program, looks up the real thing it is modelling, and checks every build before handing it over.

Is the video real time?

The requests are real, but the waiting is sped up. Everything else runs at normal speed.
